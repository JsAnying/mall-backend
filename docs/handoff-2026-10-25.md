## 4. 当前后端结构与注册流程

```text
src/main/java/com/zhf/mall/
├── AiSpingbootApplication.java
├── common/
│   ├── GlobalExceptionHandler.java
│   ├── Result.java
│   └── ResultCode.java
├── config/
│   ├── JsonConfig.java
│   └── PasswordConfig.java
├── controller/UserController.java
├── dto/
│   ├── command/UserRegisterCommandDTO.java
│   └── response/UserRegisterResponseDTO.java
├── entity/User.java
├── exception/BusinessException.java
├── mapper/UserMapper.java
└── service/
    ├── UserService.java
    └── impl/UserServiceImpl.java
```

注册流程：Command 校验 → Lambda 条件查重 → BCrypt 编码 → 设置默认昵称和 UTC 时间 → BaseMapper.insert → 检查影响行数与回填主键 → 返回响应 DTO。Service 使用事务，数据库唯一索引兜底处理并发重复用户名。

- 用户名：trim 后 3～32 位字母、数字或下划线，数据库中不区分大小写唯一。
- 密码：@NotBlank、6～64 位、UTF-8 最多 72 字节，保留首尾空格，不自动 trim。
- Command 构造器/Setter 负责用户名标准化；Service 再调用同一套 Validator，不能绕过校验。
- Mapper 使用 @Mapper，继承 BaseMapper<User>，没有旧 Mapper XML。
- 实体主键为 Long、IdType.AUTO；响应 DTO 的 ID 为 String。
- 密码/哈希排除在 JSON 输出和 toString 日志之外。
- JsonConfig 使用 Jackson 2，禁止数字/布尔值被隐式转换为用户名或密码。
